## 1. Связи ослабевают при одновременном выравнивании двух размеров

### Метод

Для каждой из двух совокупностей — всех 3961 активного каталога и 3859 каталогов без реферальной программы — отдельно построены пять квантильных групп подписчиков D и пять групп количества активных товаров Q. Их пересечение даёт 25 ячеек. В каждой ячейке сравнивается доля бизнесов с W>0 при наличии и отсутствии признака. Для обеих ветвей используются одинаковые веса: доля всей ячейки в рассматриваемой совокупности. Это прямая стандартизация описательных частот.

Основной вариант требует хотя бы одного наблюдения в каждой ветви каждой ячейки. Дополнительно проверены сетка 3×3, требование не менее пяти наблюдений в каждой ветви и выборка только с включённым оформлением. При ограничении R=1 границы квантилей сохранены от исходной совокупности. Ячейки без одной из ветвей не заполняются искусственно, а исключаются с явным пересчётом покрытия и весов.

### Главная таблица: каталоги без реферальной программы, n=3859

| Признак | Исходное отношение долей с заказом | После совместной стандартизации 5×5 | Доля с заказом при признаке 0 | Доля с заказом при признаке 1 |
| --- | ---: | ---: | ---: | ---: |
| Есть новые товарные публикации G+H>0 | 2,43 | 1,44 | 6,69% | 9,60% |
| Доставка S=1 | 2,96 | 1,56 | 6,05% | 9,45% |
| Оплата T=1 | 2,02 | 1,42 | 6,82% | 9,71% |
| Есть рекламные траты Z>0 | 2,14 | 1,63 | 6,78% | 11,02% |
| Есть открытия из контента O>0 | 3,72 | 2,39 | 6,00% | 14,35% |

В основном варианте все пять сравнений покрывают 3859 бизнесов и все 25 ячеек. Значения в последних двух столбцах — стандартизированные доли, а не фактическая частота одной непосредственно наблюдаемой группы.

**Что нового относительно прежнего анализа.** Для товарных публикаций отношение 2,43 уменьшалось до 2,01 при выравнивании только по подписчикам или до 1,75 только по каталогу. При одновременном учёте обеих грубых групп оно равно 1,436. Для всех активных каталогов аналогичное отношение равно 1,971; различие с вариантом без рефералов нельзя приписать единственной причине, поскольку меняются совокупность и её квантильные границы.

### Ограничение малых ячеек видно количественно

В сравнении товарных публикаций без рефералки в некоторых ячейках имеется только один бизнес с публикациями; в 14 из 25 ячеек среди таких бизнесов нет заказов. Если требовать минимум пять наблюдений в каждой ветви, остаются 16 ячеек и **2533 из 3859 бизнесов, 65,64%**. Отношение равно 1,401. Это результат для другой, более узкой совокупности; нельзя назвать его более точной оценкой для всех 3859 бизнесов.

При сетке 3×3 отношение для товарных публикаций равно 1,632, при основной 5×5 — 1,436. Поочерёдное исключение одной ячейки из сетки 5×5 даёт диапазон 1,238–1,534. Этот диапазон — проверка зависимости от состава, а не доверительный интервал.

Для доставки в этой совокупности во всех 25 ячейках есть не менее шести бизнесов с подключением; требование минимум пять не исключает ни одной записи. Поэтому результат 1,562 не опирается на ветви из одного–четырёх бизнесов. Это полезное различие в диагностике устойчивости связей.

**Допустимое следствие:** часть исходных различий связана с неодинаковым составом групп по размеру аудитории и каталога; оставшаяся описательная связь сохраняется при рассмотренных вариантах. **Недопустимое утверждение:** подключение доставки увеличит вероятность заказа на 56%, а публикации на 44%. Не учтены качество предложения, намерение покупателя, возраст бизнеса, момент подключения, другие признаки и обратная связь между продажами и использованием инструментов. O>0 особенно нельзя трактовать как независимое воздействие: это одновременно наблюдаемый результат интереса.

Данные для notebook: `joint_standardization_summary.csv`, `joint_standardization_strata.csv`; точные границы квантилей — `robustness_results.json → joint_standardization.quantile_edges`.

## 2. Число кандидатов устойчивее, чем аргумент о рекламном бюджете

### База сравнения

Прежняя строгая группа — Q>0, W=0, G+H=0, E+F>0, AA=0, V=0 — содержит 1817 бизнесов. База дополнительных проверок — её 366 участников с D≥1000, I≥1000, Q≥10 и R=1. Фильтр не доказывает отсутствие внешних продаж или прошлых внутренних заказов.

### Сдвиг двух порогов на 20%

Сохраняются Q≥10 и R=1:

| Минимум подписчиков | Минимум обычных просмотров | Кандидатов | Добавлено к исходным 366 | Исключено из исходных 366 |
| ---: | ---: | ---: | ---: | ---: |
| 800 | 800 | 410 | 44 | 0 |
| 800 | 1000 | 396 | 30 | 0 |
| 1000 | 800 | 375 | 9 | 0 |
| 1000 | 1000 | 366 | 0 | 0 |
| 1000 | 1200 | 355 | 0 | 11 |
| 1200 | 1000 | 345 | 0 | 21 |
| 1200 | 1200 | 336 | 0 | 30 |

Одновременное снижение обоих порогов даёт +12,02% кандидатов, повышение — −8,20%. В полной сетке 3×3 около исходного порога изменение тематического состава невелико: полная вариация распределения тематик составляет максимум 0,033. Она определена как половина суммы абсолютных разностей долей тематик. Это характеристика устойчивости состава, а не оценка достоверности.

У 11 исходных кандидатов ровно 1000 подписчиков, у пяти ровно 1000 обычных просмотров, у 14 ровно десять товаров. На хотя бы одной границе находятся 28 разных бизнесов. Замена всех трёх «≥» на «>» меняет 366 на **338**, то есть исключает 7,65%. Точные операторы фильтра должны быть сохранены в методике и коде.

### Порог каталога меняет состав сильнее

При D≥1000, I≥1000 и R=1:

| Минимум активных товаров | Кандидатов | Бизнесов с рекламными тратами | Рекламные траты группы |
| ---: | ---: | ---: | ---: |
| 1 | 599 | 67 | 28 696 300 ₽ |

Повышение Q≥10 до Q≥20 уменьшает число кандидатов на 29,51%, а сумму рекламных трат на 79,81%. Крупнейшая рекламная запись ID=4206 имеет 18 товаров и перестаёт проходить фильтр. Её 17 млн ₽ объясняют 90,48% арифметического уменьшения суммы. Это чувствительность описательного бюджета к одной записи, не доказательство плохого бизнеса или ошибки в источнике.

### Профиль 366 уточняет, кого предстоит исследовать

- Рекламные траты есть у **39 из 366, 10,66%**. Медиана среди всех кандидатов равна нулю; среди 39 рекламодателей — **61 000 ₽**, среднее — 603 633 ₽.
- Пять крупнейших рекламодателей дают 88,61% трат группы. Исключение одного ID=4206 оставляет 365 кандидатов, но только **6 541 700 ₽** из 23 541 700 ₽. Медианы подписчиков и обычных просмотров не меняются: 2900 и 9100.
- У **351 из 366, 95,90%**, нет открытий из контента. У остальных 15 суммарно 81 открытие. Положительные товарные просмотры есть у 89 из 366. Значительная обычная контентная аудитория по I не доказывает наличие товарного интереса по L/O.
- 64 бизнеса, исключённые на последнем шаге из 430 из-за R=0, имеют медианы **6300 подписчиков, 20 000 обычных просмотров и 70 товаров**. У прошедших 366 эти медианы — 2900, 9100 и 39. Следовательно, этот фильтр выбирает состояние инструмента, а не только более крупную или активную аудиторию.

**Практическое следствие:** группу можно использовать как воспроизводимый список для диагностики, но рекламные суммы нельзя считать бюджетом типичного участника или гарантированным ресурсом проекта. Вопросы о новом товарном интересе и включении оформления нужны отдельно. Проверки порогов не устанавливают оптимальный порог и не доказывают коммерческий потенциал.

## 3. Условный пилот на 366 бизнесах выявляет лишь сравнительно крупный эффект

Это **сценарный расчёт**, а не оценка будущей конверсии из данных. Участники отобраны по W=0 в прошедшем месяце; это не означает нулевую вероятность заказа в будущем контрольном периоде.

### Заданные условия

Один заранее выбранный бинарный исход на бизнес: хотя бы один квалифицирующий внутренний заказ за одинаковое будущее окно. Независимые бизнесы с одинаковой вероятностью исхода внутри каждой ветви случайно распределены 1:1; двусторонний точный тест Фишера при α=0,05. Нет перетоков между группами, последовательной остановки, кластеризации или множественного выбора метрики. Исход будущей группы контроля, участие и эффект — введённые допущения.

Мощность вычислена точным суммированием совместного биномиального распределения по области отклонения теста Фишера. Для равных групп условное гипергеометрическое распределение симметрично. Реализация проверена на 21 таблице сравнением с `scipy.stats.fisher_exact`, включая редкие исходы и вырожденные таблицы. Здесь «точный» означает способ вычисления при заданных допущениях, а не достоверность самих допущений.

### Пример: будущая частота в контроле условно 3%

| Всего анализируемых бизнесов | В каждой группе | Мощность для 3%→6% | Мощность для 3%→8% | Мощность для 3%→13% | Частота в воздействии для мощности 80% |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 366 | 183 | 20,00% | 47,61% | 93,97% | 10,66% |
| 430 | 215 | 24,70% | 56,04% | 97,10% | 9,85% |
| 684 | 342 | 40,79% | 78,88% | 99,86% | 8,08% |

Для исходных 366 кандидатов мощность 80% в этом сценарии достигается при росте примерно с 3% до **10,66%**, то есть на **7,66 процентного пункта**. При участии только 80% — 292 анализируемых бизнеса, 146 на ветвь — для той же мощности нужна частота примерно **11,96%**, на 8,96 п.п. выше контроля. При участии 50% остаётся 182 бизнеса и необходимая частота составляет 15,41%.

При эффекте 3%→8% мощность у 366 исходных кандидатов при участии 100% / 80% / 50% составляет **47,61% / 36,38% / 20,16%**. Поэтому отсутствие значимого результата небольшого теста ещё не опровергает умеренный эффект.

Числа 430 и 684 показаны только как сценарные размеры: это другие и менее строгие пулы, включающие бизнесы с выключенным оформлением и/или меньшим каталогом. Нельзя увеличить размер эксперимента механически и одновременно сохранить прежнее описание целевой группы.

**Практическое следствие:** до обещания результата нужно выбрать минимально полезный эффект, уточнить будущую частоту в контроле и фактическое участие. По текущему срезу нельзя обосновать длительность теста, будущий эффект, бюджет или универсально достаточное число участников. Нет основания выбирать 3% как «правильную» контрольную частоту: в файлах также сохранены сценарии 1%, 5% и 10%.

Данные для notebook: `pilot_power_scenarios.csv`, `pilot_power_mde.csv`. Можно показать матрицу «размер × эффект» и отдельную таблицу допущений. Для текста достаточно одного явно условного примера 3%→8%, без представления мощности как рыночного прогноза.

## Воспроизведение и встраивание

Запуск только из исходного XLSX, без зависимости от прежних вычисленных CSV:

```bash
python robustness_analysis.py --source path/to/dataset.xlsx --output-dir path/to/results
```

Или в notebook:

```python
from robustness_analysis import run_analysis
extra = run_analysis(DATASET_PATH, RESULTS_DIR / 'extra_robustness')
```

Зависимости: pandas, numpy, scipy и openpyxl для чтения XLSX. Новые модели не обучаются, внешние источники не используются. Полный JSON содержит методические ограничения, исходный SHA-256, все строки диагностик и сценарные допущения. CSV предназначены для таблиц и графиков notebook, а не заменяют исходник.
